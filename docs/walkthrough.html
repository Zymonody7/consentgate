An annotated walkthrough of one disclosure request

One request, four artefacts

This page exists because a decision is easy to describe and hard to see. Below is the actual message that arrives, the consent letter it is judged against, the message that leaves, and the audit row that ties them together. Field references are to HL7 v2.5.1.

OBX-2 ED = encapsulated data. The value is source^type^subtype^encoding^payload: a PDF, base64. The production decodes it, stores it as document #9 with provenance EMBEDDED, and the agent cites it in the same decision.

Reproduce all of this with ./scripts/demo.sh 001 and ./scripts/demo.sh 007. The consent letters themselves live in ConsentGate_Data.ConsentDoc; the field-by-field mapping from LOINC to consent category is in ConsentGate.Data.CodeMap.
